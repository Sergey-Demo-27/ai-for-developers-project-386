# Feature-Sliced Design для клиентского приложения

Клиент (`client/src/`) разложен по методологии Feature-Sliced Design: слои
`app → pages → widgets → shared`, слайс импортирует только слои ниже и только
через свой публичный API (`index.ts`). Выбрали FSD ради предсказуемой структуры
по мере роста числа страниц (`/booking`, `/events`); альтернатива — плоская
папка `components/`. Слои и слайсы заводим лениво, без пустых заготовок;
правила импортов пока держатся договорённостью, инструмент не подключён.
